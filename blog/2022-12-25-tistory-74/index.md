## Project Start

이번 프로젝트의 기획은 help + programmers 의미를 가진 프로젝트였다.

알고리즘 공부 중 어려움이 생겼을 때, 도움은 받고싶지만.. 정답이 알고싶은게 아니다. 어떠한 키워드나 작은 힌트를 얻어서

'내 스스로 풀고싶은 욕구'

그게 **프로젝트 핵심** 이다.

상세 페이지 : question 질문에 대한 CRUD 였다.

> create : 게시글 생성
> read : 게시글 읽기
> update : 게시글 수정, 업로드
> delete : 게시글 삭제

이번 프로젝트는 json-server 를 활용해서 axios로 통신해야 했다.

이번에도 crud 를 깊게 이해하고 숙달해 해서, 다음 프로젝트에는 색다른 기능 구현을 맡고싶다.

아직은 초기 단계라 글의 소재가 부족하다..!

다음 WIL 에서 프로젝트에 대해 많이 쓰겠다.
