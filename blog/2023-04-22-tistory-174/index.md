## 1. 기술 질문

- 바닐라 자바스크립트에서의 에러나 예외처리 한 경험이 있나요?
- forEach랑 map의 차이점은 무엇인가요?
- 비동기 언어와 동기 언어가 무엇인지?
- css 활용 잘하는지?
- React 라이프 사이클 useEffect useCallback에서 의존성은 어떻게 관리되는지?
- 비동기 처리 경험과 어떤 상황에서 주로 사용하는지?
- next.js 활용하면서 좋았던 점, 어려웠던 점
- 어떤 상태관리 사용했는지 왜 사용했는지, 그럼 상태관리 하면서 어떤 경우에 활용했고 어떤 데이터를 다뤘는지?
- 서버에서 받아오는 데이터 구조가 복잡한 경우를 어떻게 대처해 보셨나요?(객체 안에 객체 안에 객체 등)
- 서버에서 받아오는 데이터를 어떻게 최적화해 보셨나요?
- Authentication(회원가입/로그인) 구현 해보셨나요?

## 2. 컬쳐 핏

- 최근 어떤 서비스를 보고 좋다고 느낀게 있으신가요?
- 유튜브 어떤 채널 구독하는지 말씀해 주세요
- 가장 최근에 언제 화냈고 왜 화내셨나요?
- 스트레스 어떻게 푸시나요?
- 회사 고르면서 어떤 문화가 있으면 좋겠다고 느끼셨나요?
- 프로젝트 하면서 다툼이 있었다면 어떻게 풀어나갔는지 말씀해 주세요
- 팀 리더 경험이 있을까요?
  - 팀 리더 역할일 때, 프로젝트에서 시간이나 업무 관리를 어떻게 하셨나요?
- 프로젝트에서의 역할과 본인의 비중은 얼마나 되었다고 생각하는지
- 어떤 개발자가 되고싶으신가요?
- 전 회사에서 왜 그만두게 되었을까요?
- 삶에서 가장 어려웠던 순간이 있었다면, 어떻게 해결하셨는지 말씀해 주세요
- 취미가 무엇인가요?
- 상사와 의견이 안맞으면 어떤식으로 대처하나요?
- 브랜딩이 빠른 개발이 우선인가요? 코드를 먼저 이해하는 개발이 우선인가요?

## 느낀점

1. 디테일한 기술 면접은 회사와 면접자가 서로의 수준이나 기초 역량을 파악 할 수 있는 시간인 것 같습니다.
2. 기술질문이 없는 회사의 면접 질문은 제외하였습니다.
3. 대부분 대답을 하였으나, 긴장 하니 대답을 길게하면서 질문의 논점이 흐려지는 느낌이 있었습니다.
4. 아쉬운 부분은 추후 업로드 할 예정입니다.
5. 면접 질문을 생각보다 길게 준비했는데 준비한 질문은 거의 나오지 않았습니다..
6. 개발직군의 자기소개는 비중이 낮은 것 같습니다. 질문의 빈도는 거의 5대 5로 회바회인 것 같습니다. (30초 정도 분량으로 간략하게 준비하길 추천합니다.)
