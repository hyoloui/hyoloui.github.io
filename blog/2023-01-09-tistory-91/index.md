## Project Start

'helprogrammers' 라는 Redux / RTK / thunk 활용한 프로젝트를 성공적으로 마치고 새로운 팀이 배정되었다.

이번 프로젝트 첫 회의에 나온 공통적 의견으로 '기본에 충실하자' 라는 의견이 다수이기에 특별한 기능에 촛점을 맞추기 보다는, **이해도 높은 작업**에 기반한 프로젝트를 진행하기로 결정되었다.

방대한 라이브러리, 학습 범위로 인해 다들 지친 기색이 역력했다.. 물론 나 포함😥

프로젝트 컨셉은 세계적으로도 발생하는 **신조어가 타겟**이 되었다, 기성세대가 알아듣기 어려운 신조어의 의미와 뜻을 유저들이 자유롭게 작성할 수 있는 서비스이다.

재미있는 프로젝트가 될 것 같다. 하지만 이번 프로젝트는 새롭게 React-Query를 학습하고 적용해야 하기때문에 쉽지만은 않을 것 같다..

## Study review

React Native 를 배우니 실로, 다른 학습에 비해 상대적으로 높았다.

하지만 짧은 시간 안에 여러가지의 라이브러리를 경험하다 보니 그전에 배웠던 부분이 빠르게 달라지고 보는 시각이 지속적으로 바뀌었다.

여러 라이브러리를 습득하고, 적용하는 프로젝트를 지속하면서 장점과 단점이 있지만 스스로 센스있게 **선별해서 학습 하길** 바래본다.

### React-Query를 학습하면서 느낀 점은,

thunk를 학습할 때 느낀 번거로운 점이 한꺼번에 해결이 되었다.

반복되는 코드, 가독성이 떨어지는 복잡한 코드가 너무 간결해졌고, 퍼포먼스 적으로도 매우 향상되었다는 느낌을 많이 받았다!

실제로 현업에서 react-query의 사용, 인기도가 날로 늘어나고 있다고 하니

깊게 습득해서 서버통신을 완벽히 이해하고 몸에 베었으면 좋겠다!
