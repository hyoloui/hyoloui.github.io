## Study review

자료구조, 알고리즘을 발표하면서 느낀점은 내가 지금까지 알고리즘 풀이 방법이 너무 막 풀었다고 생각했다.

이렇게 많은 방법론과 데이터 구조를 숙지하고 공부했다면 일관성있는 알고리즘 풀이를 했을 것 같다.

하지만, 나만의 풀이 방법대로 진행하면서 지금까지 생각하지 않았던 창의적인 생각도 조금씩 묻어나온 것 같다.

이제 문제풀이를 하면서 내가 학습했던 것(이진탐색트리, DFS, BFS)을 대입하는 연습을 해야겠다.

## 프리온보딩 챌린지 review

React를 사용하면서 깊게 생각해 보지 않은 내용(가상돔, 실제돔)들을 다뤘고 핵심으로 React v18.0 의 신기능을 대입해서 흥미로운 강의였다.

![Vite + React 기본 화면](./img-01.png)

또한 vite(빗)을 새로 알게되었다. 프랑스어로 '빠르다'라는 뜻으로 이전까지는 Create React App 이 리액트의 주된 빌드툴 이였다면, 새롭게 출시 한 빌드툴이다.

주요 장점으로는 build 시 체감속도가 웹팩보다 매우 빠르며 실무에서 급한 버그를 처리하기 위한 hotfix를 진행할 때 톡톡히 효과를 볼 수 있으며,

주요 단점으로는 lazy component를 적용할 수 없다. dynamic import는 rollup 설정을 통해 사용 가능하지만 lazy component의 경우 vite/rollup 구성에서 지원이 안된다.

## 알고리즘 문제풀이

매일 2문제를 풀면서 느낀점은 vanilla javascript의 자체 메서드가 많지만, 목적에 맞게 잘 사용하고 손에 익으면 아주 쉽게 풀 수 있을 것 같았다.

0레벨을 마무리하고 1레벨로 넘어갔는데 아직 초반이라 그런지 생각보다는 조금만 생각하면 풀 수 있었다.

이러한 문제를 앞으로 풀어나가면서 학습한 자료구조, 정렬, 탐색을 대입해서 풀면 좋으련만 아직 배워야 할 것들이 많다.
