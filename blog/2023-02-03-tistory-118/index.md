## Study review

부족하다고 생각했던 자바스크립트를 900페이지가 넘는 모던 자바스크립트 - 딥다이브 교재를 활용해서 한챕터 한챕터 서로가 준비하고, 발표하면서 깊게 공부하는 과정이 있어 스터디 그룹에 들어가길 정말 잘했다🤩

내가 담당한 발표는 아래와 같다.

- 4 - 변수
- 8 - 제어문
- 12 - 함수
- 16 - 프로퍼티 어트리뷰트
- 20 - strict mode

이렇게 일주일에 5챕터를 발표했고, 공부한 양이 꾀나 되어 벌써 절반정도 되었다.

자바스크립트 공부는 위처럼 진행했고, 이어서

**next.js** 강의를 보면서 CSR SSR SSG ISR을 각 이해하고 어떻게 쓰는지를 다뤘다.

|                      | CSR | SSR | SSG | ISR      |
| -------------------- | --- | --- | --- | -------- |
| 빌드 시간                | 짧다  | 짧다  | 길다  | 길다       |
| SEO                  | 나쁨  | 좋음  | 좋음  | 좋음       |
| 페이지 요청에 따른 응답 시간 | 보통  | 길다  | 짧다  | 짧다       |
| 최신 정보인가?             | 맞음  | 맞음  | 아님  | 아닐 수 있음 |

TIL에는 next.js를 남기지 못해서 이번 주말에 다시 복습하며 포스팅 할 예정이다.
