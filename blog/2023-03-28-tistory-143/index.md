> RegExp는 정규 표현식입니다. (Regular expression)

## RegExp

### 정규 표현식이란?

일정한 **패턴을 가진 문자열의 집합**을 표현하기 위해 사용하는 **형식 언어(formal language)** 다. 정규 표현식은 자바스크립트의 고유 문법이 아니고, 대부분의 프로그래밍 언어와 코드 에디터에 내장되어 있다.

정규 표현식은 **패턴과 플래그로 구성**된다.

### 정규 표현식의 생성

정규 표현식 객체(`RegExp` 객체)를 생성하기 위해서는 정규 표현식 리터럴과 `RegExp` 생성자 함수를 사용할 수 있다.

일반적인 방법은 정규 표현식 리터럴을 사용하는 것이다. 정규 표현식 리터럴은 다음과 같이 표현한다.

```js
const 영어 = 'Is this all there is?';

// 패턴 : is
// 플래그 : i => 대소문자를 구별하지 않고 검색
const regexp = /is/i;

regexp.test(영어); // true
```

`test` 메서드는 `regexp`의 패턴을 검색하여 매칭 결과를 **불리언 값으로 반환**한다.

`new RegExp` **생성자 함수**를 사용해 동적으로 객체를 생성할 수 있다.

### RegExp 메서드

- `.exec` (= 패턴의 검색 결과를 배열로 반환)
- `.test` (= 패턴의 검색 결과를 boolean으로 반환)
- `.match` (= 정규 표현식과의 매칭 결과를 배열로 반환한다.)

### 플래그

총 6가지가 있지만, 그중 중요한 3개의 플래그만 설명한다.

**`i`**

대소문자를 구별하지 않고 패턴을 검색한다.

**`g`**

대상 문자열 내에서 패턴과 일치하는 모든 문자열을 전역 검색한다.

**`m`**

문자열의 행이 바뀌더라도 패턴 검색을 계속한다.

### 패턴

패턴은 `/`로 열고 닫으며 문자열의 따옴표는 생략한다. 따옴표를 포함하면 따옴표까지도 패턴에 포함되어 검색한다.

**`/문자열/플래그`** 예) `/abc/g`

이렇게 패턴과 플래그를 조합하고 위에 설명한 메서드를 사용하여 다양한 기능을 구현할 수 있다.

- 문자열 검색
- 임의의 문자열 검색
- 반복 검색
- OR 검색
- NOT 검색
- 시작 위치로 검색
- 마지막 위치로 검색

### 자주 사용하는 정규 표현식

- 특정 단어로 시작하는지 검사 (이메일, url 등)
- 특정 단어로 끝나는지 검사 (파일 확장자, 이메일 도메인 등)
- 숫자로만 이루어진 문자열인지 검사 (연락처)
- 하나 이상의 공백으로 시작하는지 검사 (input 첫 빈 문자열 검사)
- 아이디로 사용 가능한지 검사 (알파벳 대소문자 또는 숫자로 끝나며 4~10 자리인지 검사한다.)
- 메일 주소 형식에 맞는지 검사
- 핸드폰 번호 형식에 맞는지 검사
- 특수 문자 포함 여부 검사

:::tip 최종 정리

1. 일정한 **패턴을 가진 문자열의 집합**을 표현하기 위해 사용하는 **형식 언어(formal language)**
2. 정규 표현식은 **패턴과 플래그**로 구성된다.
3. 자주 사용하지 않기 때문에 외우는 것보다 필요할 때 가져오고, 패턴과 플래그만 알고 있다면 해석하기 수월하다.
4. 정규 표현식을 작업할 때는 `console.log()` 함수보다는 `RegExp.test()`를 통해 검사하는 게 빠르다.

:::
