## 🧱 Project Start

프로젝트 진행이 거의 마무리 되었고, 우리가 맡게 된 메인페이지와, Youtube API 통신은 끝나게 되었다.

그래서 타입스크립트로 리펙토링을 진행했고, 쉽지 않았다. 하지만 같은 포지션을 담당(페어) 조원분과 **Live Share 를 활용해 페어코딩**을 처음 경험했다.

그리고 typescript로 진행하며 만난 수 많은 에러(피범벅)들을 빠르게 해결해 나갈 수 있었다.

팀으로 같은 방향으로 합을 맞춰가는것은 어려운 일 이지만 방향이 잘 맞아 엄청난 시너지효과, 속도를 경험했던 것 같다.

서로 배려하면서 시간 가는 줄 모르고 코딩을 했고, 한 사람이 문제에 도달했을 때 다른 사람의 시선으로 해결방안(솔루션)이 나오는 경우가 많았다.

이번 프로젝트로 다시한번 **팀워크의 중요성**을 깨닳은 것 같다.
