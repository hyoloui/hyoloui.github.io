## 프로그래밍? 코딩?

그래서 그게 뭔데...

컴퓨터가 이해 할 수 있는 언어로 정해진 방식(문법)에 따라 일 할수 있도록 작성 해 놓는것이다.

이후 코드를 읽은 컴퓨터는 **입력 👉 처리 👉 출력** 순서가 되어 컴퓨터가 일한다.

## Javascript?

Java랑 똑같은 거 아니야?

네 아닙니다! 자바스크립트와 자바는 '인도 와 인도네시아' 처럼 서로 다른 이름으로 생각 하시면 됩니다.

자바스크립트는 공식적으로 채택되어 인터넷에 접속한다면 우리가 설치하지 않아도 PC, Mobile 환경에서 사용하는 공용어 입니다!

Web 에서 browser (크롬, 사파리, 인터넷익스플로러 등)가 사용하는 유일한 언어이기도 합니다!

## 그럼 Node.js는 뭐에요..?

위에서 언급 한 것처럼 javascript 는 브라우저에서 구동이 가능 하지만, 브라우저가 아닌 곳에서도 사용 할 수 있도록 해주는 일종의 자바스크립트 전용 번역기 입니다!

## 주석이 뭐지?

`//` 👈 주석은 이 녀석으로 시작합니다.

언어별로 주석 처리 방법은 다르지만 자바스크립트에선 통상 `//` 이 맨 첫글자가 되면 뒤에 붙은 텍스트는 **컴퓨터가 읽지 못하고 건너뛰게 됩니다**~ 한마디로 우리 사람 눈에만 보이는 것입니다.

예시로 `// 내 컴퓨터 바보` 이렇게 작성하면 이해하지 못하고 넘어가게 됩니다.

그래서 편의상 코딩 할 때 이렇게 작성하면 유지 보수에도 편하고 협업에도 좋습니다! 주석 열심히 달아주는 센스!

```js
// 코딩의 목적( 기능) ex: 게시글 완료 버튼
function button() {
  // ~코드~
}
```
