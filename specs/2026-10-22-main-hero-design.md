## 의도

hyoloui.github.io 메인(`/`)을 채용용 소개 페이지로 바꾼다. 읽는 사람은 HR 담당자와 프론트엔드 채용 담당자다. 첫 화면에서 "어떤 일을, 얼마나 오래, 어떤 성과로 했는지"를 파악하고, 이력서·포트폴리오·자기소개(Notion 공개 페이지)로 넘어가게 하는 것이 목적이다.

본인이 강조하려는 세 가지:
1. 계속 성장하는 사람이다 (퍼블리셔 → 어시스트핏 단독 FE → 학업 병행 → AI와 함께 일하기).
2. AI를 쓰되 결과는 검증한다.
3. 어시스트핏 서비스를 오래 운영했다 (2023.05 입사, 2024.08 정식 출시).

## 모션·인터랙션 (yceffort.kr 분석 반영, 사용자 요청)

2026-10-22에 yceffort.kr 메인의 CSS(StyleX)와 JS 번들에서 값을 직접 뽑았다. 아래 값을 그대로 쓴다. 시안 v3(`full-page.html`)에 같은 동작을 넣어 두었다.

| # | 대상 | 동작 | 값 (yceffort 원본) |
|---|---|---|---|
| 1 | 히어로 아이브로우 | 처음 뜰 때 아래에서 위로 나타남 | translateY(10px)→0, opacity 0→1, `.45s cubic-bezier(.2,.9,.2,1) both` |
| 2 | 아이브로우 점 | 숨 쉬듯 깜빡임 | opacity 1→.3→1, `1.6s ease-in-out infinite`, `box-shadow: 0 0 12px` 분홍 |
| 3 | 그라디언트 글자 (`수치로 고르는`, `AI와 함께 일하기`, 이메일) | 색이 천천히 흐름 | `linear-gradient(120deg, 보라 0%, 중간색 50%, 분홍 100%)`, `background-size:200% 100%`, background-position 0%→100%→0%, `10s ease-in-out infinite` |
| 4 | 히어로 제목 두 줄 | 마우스 위치에 따라 줄마다 다른 거리로 움직임(패럴랙스) | 창 기준 포인터 위치(-.5~.5) × `(줄 번호+1)×6px`, `translate3d`, `requestAnimationFrame`으로 묶음, `transition: transform .12s ease-out` |
| 5 | 커서 글로우 | 마우스를 늦게 따라오는 보라 빛 | 500px 원, `radial-gradient(circle, 보라 0%, transparent 60%)`, opacity .08(다크 .12), `blur(20px)`, `position:fixed`, left/top `.4s cubic-bezier(.2,.9,.2,1)` |
| 6 | AI 카드, Fit HR 카드 | hover 시 테두리·그림자, 마우스 방향으로 3D 기울기와 스포트라이트 | 테두리 보라, `box-shadow: 0 10px 40px -20px 보라`(.2s). 기울기 `perspective(1200px) rotateX((.5-y)×8deg) rotateY((x-.5)×8deg)`, 떠나면 0으로. 스포트라이트 `radial-gradient(400px circle at --mx --my, 보라 10%, transparent 45%)` |
| 7 | Work 행 | hover 시 배경이 옅게 칠해짐 | `transition: background .2s`, 보라 5% 정도 |
| 8 | 버튼 | hover 시 색 전환 | color·background `.18s`, transform `.18s cubic-bezier(.2,.9,.2,1)` |

제 판단으로 더하거나 바꾼 것:
- 히어로 등장(1)을 제목(.06s)과 소개·숫자 묶음(.12s)에도 같은 효과로 순서대로 적용한다. yceffort는 아이브로우에만 쓴다.
- 버튼 hover에 1px 위로 뜨는 효과를 넣는다.
- Work 행에는 yceffort의 "오른쪽 화살표 4px 이동"을 넣지 않는다. 행이 링크가 아니라서 클릭할 수 있는 것처럼 보이면 안 된다.

모든 모션에 지키는 규칙 (yceffort도 같음):
- `prefers-reduced-motion: reduce`이면 위 모션을 모두 끈다. JS 효과(4, 5, 6)는 시작하지 않는다.
- 4, 5, 6은 마우스가 있는 기기(`(hover:hover) and (pointer:fine)`)에서만 켠다. 터치 기기에서는 끈다.
- pointermove는 `passive: true`로 듣고, 언마운트할 때 리스너와 rAF를 정리한다.
- 새 의존성(framer-motion 등) 없이 CSS와 작은 React 훅으로 만든다.

이번에 넣지 않는 것 (사이트 공통 영역이라 범위 밖, 따로 제안 가능):
- 다크 모드 전환 시 클릭 위치에서 원이 퍼지는 효과(View Transition `circle-clip`, .5s). Docusaurus 테마 토글을 swizzle해야 한다.
- 페이지 이동 시 좌우 슬라이드(View Transition, 30px, .3s).
- 화면 전체 노이즈 질감(grain). yceffort도 기본은 꺼져 있다.

- 작업은 새 브랜치에서 하고, 로컬 확인(완료 기준 1~3)까지만 한다. main 병합과 push(= 배포)는 사용자가 결과를 본 뒤 요청할 때 한다.
